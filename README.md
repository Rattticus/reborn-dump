# reborn-dump
A [Fleasion](https://github.com/fleasion/Fleasion) gamedump of [PARKOUR Reborn](https://www.roblox.com/games/11639495622/PARKOUR-Reborn)


## Tutorial: Custom Skyboxes

### Step 1: Adding the dump to Fleasion
Open "Scraped Games"
![Tutorial Image 3](https://github.com/Rattticus/reborn-dump/blob/main/tutorial-images/Screenshot%202026-09-16%20204624.png?raw=true)

Link: https://raw.githubusercontent.com/Rattticus/reborn-dump/refs/heads/main/reborn_dump.json
![Tutorial Image 2](https://github.com/Rattticus/reborn-dump/blob/main/tutorial-images/Screenshot%202026-09-16%20204734.png?raw=true)

### Step 2: Removing Reborn's Skybox
Open "Assets"

![Tutorial Image 3](https://github.com/Rattticus/reborn-dump/blob/main/tutorial-images/Screenshot%202026-09-16%20211333.png?raw=true)

Select "Skybox"

![Tutorial Image 3](https://github.com/Rattticus/reborn-dump/blob/main/tutorial-images/Screenshot%202026-09-16%20204801.png?raw=true)

Leave "Replace With" empty (1), and enable the profile (2)

![Tutorial Image 4](https://github.com/Rattticus/reborn-dump/blob/main/tutorial-images/Screenshot%202026-09-16%20204817.png?raw=true)

### Step 3: Replacing Default Skybox

Go to Modifications (3), and replace the skybox images with your desired skybox from "Replacements" (see image 3), or from anywhere else

![Tutorial Image 4](https://github.com/Rattticus/reborn-dump/blob/main/tutorial-images/Screenshot%202026-09-16%20204837.png?raw=true)
